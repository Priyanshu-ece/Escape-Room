# 🧪 Escape Room: The Abandoned Lab

A Python-based 2D escape room game built using Pygame.

## 🎮 Game Story

You wake up inside an abandoned laboratory.

The lights are out.

You must explore the laboratory, find useful items, restore power, access the security terminal, obtain the keycard, unlock the exit door, and escape before time runs out.

## 🧩 Game Flow

Flashlight
→ Drawer
→ Screwdriver
→ Power Box
→ Correct Switch Sequence (1 → 2 → 3 → 4)
→ Restore Power
→ Computer Terminal
→ Password: LAB
→ Security Keycard
→ Exit Door
→ Emergency Code: 2026
→ Escape!

## ✨ Features

- Interactive escape room gameplay
- Dark laboratory environment
- Flashlight exploration
- Inventory system
- Power restoration puzzle
- Computer terminal puzzle
- Security keycard system
- Door keypad puzzle
- Countdown timer
- Sound effects and background music
- Lab light flickering effects

- Drawer opening animation
